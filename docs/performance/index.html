Using this guide

AWA is the wind angle commonly felt and displayed aboard. TWA describes the course relative to true wind. Optimum beat and run angles maximize VMG toward a windward or leeward mark.

ORC predictions use wind referenced at 10 metres above the water. This independent rating polar is not an official ORC Speed Guide and does not identify individual sail choices.
